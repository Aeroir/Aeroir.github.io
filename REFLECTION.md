When you press enter into a browser after typing your website, the browser checks each portion of information within the URL typed. It looks for https, the website itself, any paths, etc.
Then it begins to lookup for your website using its IP addresses and memory caches in order to properly provide the correct address to the website.
It then opens a connection to that correct IP address and allows for that connection to be stable, encrypted and therefore protected.
Now the website can be built using the files provided in the GitHub, so once that connection is stable, the data needed to construct the website is able to be sent and transferred.
Once the files that have been needed are used (HTML, CSS, etc), It routes through the internet and keeps track of each jump in connection for the data and construction.
Finally, the final result is ready to be finalized and it is displayed after last additional aspects have been added.
